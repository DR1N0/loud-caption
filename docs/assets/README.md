# Screenshot set

The README uses five screenshots captured on a real phone with the release
build, at the default display size, with no personal conversations or names
visible.

| File | What it shows |
|---|---|
| `captions-portrait.jpg` | 字幕 mode, portrait, live caption lines |
| `translation-mode.jpg` | 翻译 mode with a translated line under the original |
| `translate-custom.jpg` | 互译 mode with per-source routing |
| `landscape-large-font.jpg` | Landscape at a large font size, showing the side rail |
| `first-run-mobile-data.jpg` | First-run download with the mobile-data confirmation dialog |

Portrait images are 900 px wide; the landscape image is 1600 px wide. They are
optimized JPEGs (quality 85, progressive) to keep the README light. If a
screenshot is recaptured, keep the same filenames and aspect ratios.
